日期：2026-11-04。狀態：使用者已確認採用「安全帽＋健檢報告」，已納入本機第七張表單。

沿用 `src/lib/forms/art.ts` 的 240×240 viewBox、深綠圓角描邊、薄荷綠圓形底、分塊陰影、白色亮面、十字與星芒點綴。採用原生 SVG，便於後續嵌入表單管理卡片、QR code 與海報。
