供院方審閱。建議將下列三段分別發布在同一個由院方管理、可驗證所有權的 HTTPS 網域。首頁應連到同一份隱私權政策和服務條款，三頁都可在未登入時閱讀。

## 應用程式首頁

### 烏日澄清醫院 預約健檢通知

預約健檢通知協助烏日澄清醫院的工作人員掌握待確認的健檢預約。有新待辦時，系統會以電子郵件寄送摘要給院方管理者指定的收件人。通知提供待辦件數及後台連結，工作人員須登入後台並具備存取權限，才可查看及處理案件。

寄件帳號由院方管理者設定。啟用寄件時，系統會請寄件帳號持有人授予 Gmail 寄件權限，以便定時代為寄出待辦摘要。民眾填寫公開健檢表單時無須授予這項權限。

## 隱私權政策

本政策說明「烏日澄清醫院 預約健檢通知」如何使用 Google 帳號授權及處理寄件資料。

### Google 授權與資料用途

系統向指定寄件帳號請求 Gmail 的 `gmail.send` 權限，用於寄送預約健檢待辦摘要。這項權限允許代為寄信。系統不透過這項授權讀取收件匣、郵件內容或聯絡人。

系統在 Vercel 正式環境的伺服器端保管 Gmail 更新權杖和 OAuth 用戶端密鑰。有待辦需要寄送時，伺服器向 Google 交換短效存取權杖，並透過 HTTPS 呼叫 Gmail API。Google 會收到寄件與收件地址、郵件標頭，以及包含待辦件數和後台登入連結的摘要，以完成寄送。摘要不含個別案件的姓名、證件號碼、表單答案、簽名或檢查結果。

### 寄送紀錄與資料保護

預約系統會記錄收件地址、寄送批次、嘗試時間、結果及 Gmail 回傳的郵件識別碼（如有），供院方核對寄送與避免重複通知。通知寄給院方指定的收件人，案件資料仍由具權限的工作人員登入後台查閱。Google 授權及寄件資料用於提供本通知功能，依照 Google API 服務使用者資料政策的有限使用要求處理。

### 撤銷授權與資料請求

寄件帳號持有人可在 Google 帳戶的第三方連結管理頁面撤銷本應用程式的授權。撤銷後，系統便無法再用該授權寄信。若要停止通知、移除系統保管的授權憑證，或詢問寄送紀錄的保留、刪除與資料請求方式，請透過下方聯絡管道提出。

聯絡方式與寄送紀錄保留及刪除規則由院方審閱後補入。

## 服務條款

「烏日澄清醫院 預約健檢通知」供院方授權人員處理預約健檢待辦。院方管理者負責指定寄件帳號及收件人，並在工作分派變更時更新收件設定。寄件帳號應由帳號持有人或院方授權的管理者同意連結。

待辦摘要用於提醒工作人員處理案件。工作人員應登入後台查閱案件狀態及安排後續作業。民眾的預約結果以院方確認為準。請妥善保管登入及授權資訊，並避免將待辦通知轉寄給未獲授權的人員。

若有寄件異常、需變更通知設定，或需終止 Google 寄件授權，請聯絡院方管理者。Google 授權與寄件資料的處理方式見[隱私權政策](#隱私權政策)。

## 院方發布前確認

- 確認正式網域及所有權驗證方式，並核對三個網址可直接開啟。將草稿中的章節連結改成正式網頁連結。
- 確認可公開的聯絡管道、寄送紀錄的保留期限或判斷標準、刪除申請的處理方式，以及停止寄件時移除憑證的作業方式。將核准資訊填入政策並加上生效日期。
- 由院方核准政策與條款後再發布。將正式網址填入 [Google Auth Platform 品牌頁](https://console.cloud.google.com/auth/branding?project=wjcch-513908)，再依 Google Console 的提示處理正式發布與驗證。
