# 協同完成表單列表（第 6 項）設計

日期：2026-10-24　狀態：已確認

## 列表

- 選單名稱由「表單資料」改為「協同完成」（`/admin/submissions`）。
- 欄位：表單、狀態、姓名、身分證號、民眾送出時間、院所完成時間、操作。
- 操作欄：「開啟」（進入單筆頁填寫院所區）與「列印 / 另存原樣 PDF」；只有「已完成」可列印，其他狀態按鈕停用並提示確認送出後才能列印。
- 同一人同表單有其他未完成資料時標示「可能重複」。
- 每頁 50 筆，顯示總筆數與頁碼。

## 排序

- 點欄位標題的排序按鈕切換由小到大／由大到小；預設依民眾送出時間由新到舊。窄螢幕（卡片排版）時排序按鈕排成一列放在列表最上面。
- 表單依表單順序、狀態依「待院所填寫、民眾修改中、已完成、已作廢」排序；院所完成時間為空的排在最後。
- 排序、篩選、頁碼都記在網址上，重新整理或分享連結時保留。

## 複合篩選

- 條件：身分證號（包含，不分大小寫）、表單種類（6 個勾選框）、狀態（4 個勾選框）。
- 按「篩選」才套用；每個條件都可以單獨使用，填了多個條件時須同時符合。
- 某一組勾選框全部不勾，等於不限制該組；狀態預設為未作廢的三種。
- 「清除條件」把所有篩選欄位改回預設（含尚未按「篩選」的輸入）並重新列出，保留目前的排序。

## 單筆頁版面

- 上方以提示框顯示狀態與下一步（待院所填寫、民眾修改中、已完成並鎖定、已作廢）。
- 操作按鈕放在「院所填寫區」最下方，左側顯示自動儲存狀態：
  - 待院所填寫：作廢、確認送出
  - 民眾修改中：作廢、確認送出（停用，民眾重新送出後才能按）
  - 已完成：取消送出、列印 / 另存原樣 PDF
  - 已作廢：復原
- 儲存失敗或資料被他人更新時，錯誤訊息在院所區內捲動時固定在畫面下緣，填寫中途也看得到。
- 「民眾填寫內容」預設收合，右側有「展開／收合」按鈕。

## 介面原則

後台功能不多，主選單放在頂部列（不用左側選單）；內容區加寬（最寬 1360px）並置中。篩選區以「標題＋選項」橫向排列，寬螢幕只佔兩列。

凡是可以點選的功能一律做成按鈕外觀（返回、首頁提醒的「前往」、重複資料連結、排序、展開／收合、登入頁「最高管理者首次設定」、民眾端「清除此裝置上的暫存資料」等），不只用文字連結呈現。

## Schema

不新增資料表；為排序新增索引：

```sql
CREATE INDEX submissions_submitted_at_idx ON submissions (public_submitted_at DESC);
CREATE INDEX submissions_completed_at_idx ON submissions (completed_at);
```

## 測試

- 單元：網址參數解析（不合法的值忽略、預設值、勾選框全部不勾）。
- 整合：身分證號部分比對、表單與狀態篩選、預設排除作廢、各欄位排序、分頁與總筆數。
- 瀏覽器：篩選、排序、分頁、列印按鈕狀態、單筆頁按鈕位置。
