## 手機填寫流程

保留原表六大段內容，將作業經歷與檢查時期合併為一步，共五步。日期沿用現有系統的民國年月日輸入；作業經歷的起訖日期只輸入民國年、月。

| 步驟 | 原表內容與欄位 |
|---|---|
| 1. 基本資料 | 姓名、性別、身分證字號／護照號碼、出生日期、email（選填，填寫時檢查格式）。 |
| 2. 作業經歷與檢查時期 | 事業單位名稱（placeholder 提供醫院／公司名稱範例）、受僱日期、檢查日期；先填目前從事的工作，再填最近一項過去的工作，保留起訖年月與年資；是否輪班及兩班／三班／四班／其他班制；過去一個月與六個月的平均每週工時；新進員工（受僱時）或定期檢查。 |
| 3. 既往病史 | 依原表逐項複選；癌症、骨折、手術開刀、其他慢性病保留補充欄；「以上皆無」與疾病選項互斥。 |
| 4. 生活習慣 | 吸菸、嚼檳榔、喝酒各保留從未、幾乎每天、偶爾、已戒四種選項；依答案顯示數量、年資或戒除期間。喝酒保留每週次數、酒類、每次瓶數。另填工作日期間平均每天睡眠時數。 |
| 5. 自覺症狀 | 最近三個月症狀依原表逐項複選，含其他症狀補充欄；「以上皆無」與症狀選項互斥。 |

姓名、證件號、生日、性別及 email 沿用裝置的共用 `profile.*` 資料；電話、教育程度與地址不列入此表的必填，也不清除同一裝置先前填過的其他表單基本資料。受僱日期、檢查日期與事業單位名稱歸本表專用欄位，依使用者補充移到第二步。列印保留原 PDF 順序：這三項仍位於基本資料，曾經從事仍在目前從事之前；紙本沒有 email 欄，因此只保存在電子資料中。

### 必填及連動規則

- 姓名、性別、證件號、生日、事業單位名稱及檢查時期必填。證件號沿用現有系統對本國身分證、統一證號及護照的驗證。
- 曾經／目前工作以「有／無」擇一；選有時填工作名稱。輪班於目前有工作時詢問，選是時擇一班制，選其他時填說明。
- 病史、吸菸、嚼檳榔、喝酒及自覺症狀的主選項均需作答，沒有病史或症狀時明確勾選「以上皆無」。
- 勾選有補充欄的疾病或其他症狀時填說明；生活習慣選幾乎每天或已戒時填對應的數量、年資或期間。期間中的月數允許填 0。
- 受僱日期、檢查日期、作業起訖年月與年資、每週工時及睡眠時數先採選填；有填時檢查日期與數值格式。年月／年月日組填寫一部分時需補齊該組，起訖時間不可顛倒。
- 日期不預填，以免帶入與實際受僱或檢查日不同的日期；年資手動填寫。工作時數、睡眠、瓶數等可輸入合理的小數，睡眠不超過每日 24 小時，週工時不超過 168 小時；年資的月數限 0–11。
- 未顯示的分支資料在正式送出時清除，避免舊答案殘留；裝置草稿沿用既有保留分支答案的方式，便於切換後續填。原 PDF 沒有簽名欄，本表不新增簽名或同意欄。

## 後台協同

原 PDF 所有題目均為受檢者填寫，填表說明要求交由醫護確認。因此本表後台以檢視民眾填寫內容、確認完成為主，沿用原有取消送出、作廢及復原流程；不另設檢查數值、醫師結論或簽名欄。

民眾填寫內容仍預設展開，修正答案時沿用原裝置的退回修改、再次送出流程；院所確認不直接改寫民眾原答案。確認完成時仍記錄院所操作人及完成時間。

表單管理加入第七張卡片，提供開放開關、期間設定、QR code 及海報。協同列表加入「勞工健康檢查」篩選，首次進入的表單種類預設全選包含新表單，狀態仍只勾「待院所確認」；所有狀態可列印，modal、篩選保留與 loading 沿用現有功能。
