# 勞工健康檢查：資料上傳同意書規格草案

狀態：使用者已確認實作範圍；本機已完成實作與驗證。依最新確認，查詢用途說明保留於選項前方，「同意」選項不另加附註。未改實體資料表或正式環境。

## 來源與適用範圍

- 指定來源：`預防保健表單電子檔/特約醫事機構上傳民眾自費檢驗(查)結果/自費檢驗（查）、藥物、醫材資料上傳個人資料蒐集處理及利用同意書.pdf`。
- 已閱讀全文並檢視一頁 A4 原稿，尺寸 595.32 × 841.92 pt，沒有 AcroForm 欄位。
- 保留原稿標題、資料種類、目的、提供對象、各項期間選擇、雲端系統選項、權利條款、法定代理人與簽名欄位。原稿紅色文字屬正文，列印時須原樣保留。
- 依指定版本實作自費檢驗（查）、藥品及醫材資料同意書；前後台既有直接列印流程一併支援新增頁面。

## 手機填寫流程

1. 在「5 自覺症狀」後新增「6 資料上傳同意書」。先提供簡短說明及完整原文的閱讀入口，再要求選擇是否同意資料蒐集、處理及利用；兩個選項皆不預選。
2. 精簡說明草案：「同意後，本院可依您選擇的範圍與期間，將相關資料提供予健保署，載入健康存摺，方便您查閱。您也可另行選擇提供至健保醫療資訊雲端查詢系統，供醫療需要範圍內使用。」詳細區保留原文的取消同意、查詢、閱覽、複製、補充、更正、停止蒐集、處理或利用與請求刪除等權利說明。
3. 「同意／不同意」為必答；選擇不同意時隱藏其餘欄位，仍可送出健檢問卷。
   - 選項僅顯示「同意／不同意」；健康存摺及健保醫療資訊雲端的查詢用途保留於前方說明。
4. 選擇同意後分小區塊填寫：資料範圍 → 利用期間與提供系統 → 確認身分與簽署。
5. 姓名、出生年月日、身分證號／證件號沿用本次健檢基本資料，顯示確認資訊，不重複輸入；有誤時引導回基本資料修正。
6. 原稿兩處機構名稱均固定使用既有 `HOSPITAL_NAME`（烏日澄清醫院），不提供編輯欄位。

## 同意後的欄位與驗證

| 項目 | 提案規則 |
| --- | --- |
| 資料起算日 | 必填有效的民國年、月、日，不替使用者決定起算日。 |
| 涵蓋資料期間 | 必選「7 年」或「自訂年數」，不預選；自訂時填正整數年數。 |
| 提供健保署的利用期間 | 必選「自簽署日起永久」或「自簽署日起自訂年數」，不預選；自訂時填正整數年數。 |
| 健保醫療資訊雲端查詢系統 | 獨立選填勾選，預設不勾；健康存摺仍依原文列為同意的利用目的。 |
| 本人簽名 | 必須為此同意書獨立簽名，沿用現有觸控簽名板，不帶入其他表單簽名。 |
| 是否有法定代理人 | 選擇有／無；不以年齡自行判斷是否須代理人。 |
| 法定代理人資料 | 選有時填姓名、證件號及獨立簽名；證件號沿用現有證件格式檢查。本人與代理人簽名分開儲存。 |
| 簽署日期 | 預填台灣當天日期，可確認／調整；須為有效日期且不得晚於今天。 |

- 自訂年數使用窄版整數欄位，最多三位；民國年最多三位，月、日最多兩位，沿用共用日期元件的月份、當月天數及閏年檢查。
- 所有欄位均有伺服器驗證；變更同意、期間類型或代理人選項時，隱藏欄位不保留於送出資料。
- 送出後再次修改，沿用既有清除簽名、重新簽署機制；由同意改成不同意時，清除本筆同意細項與簽名。沿用目前案件覆寫方式，最新送出內容取代前一份內容，不增加歷次同意書版本保存功能。

## 儲存與共用資料契約

- 規劃以 `labor.upload*` 新 key 儲存在既有 `heal_submissions.public_data`，不改既有 key 的意義，不新增實體欄位或資料表，無須資料庫 migration。
- 欄位涵蓋同意選擇、資料起算日期、涵蓋期間模式／自訂年數、利用期間模式／自訂年數、雲端系統勾選、本人簽名、代理人有無／姓名／證件號／簽名及簽署日期。
- 實作時同步修改 `scripts/lib/submission-dictionary-metadata.ts`，產生並檢查 `docs/data/heal-submissions.md` 與 `.json`，在 `docs/data/changes.md` 記錄新 key、選項及相容讀法。
- 舊勞工案件缺少新 key 時，後台顯示「尚未填寫」，不可解讀為不同意或同意；舊案仍可檢視、列印及院所確認。退回由民眾再次送出時，需完成新增的必答選擇。
- 同意選擇與細項隨原有權限、裝置憑證、暫存時效及防重送流程保存。後台民眾填寫內容可檢視，同意書簽名不可由院所人員代改。

## 原樣列印

- 勞工健檢原紙本維持第 1 頁；同意者另附原樣同意書為第 2 頁。不同意或舊資料尚未填寫者，僅列印第 1 頁。
- 同意書由原 PDF 產生完整向量底稿，保留字形、段落、紅色文字、底線、勾選框、空白及 A4 版面，再以原始座標套印姓名、固定機構名稱、各項日期、期間、勾選、身分資料與簽名。
- 原稿「本人」前段姓名及下方身分資料由基本資料帶入；「立同意書人」放獨立本人簽名，法定代理人欄放代理人姓名／簽名，下一行放代理人證件號。
- 前台成功送出、後台列表與案件 modal 的列印均沿用直接進入瀏覽器列印介面的流程；載入等待須涵蓋新增底稿與簽名圖片。

## 驗證範圍

- 同意選擇必填；不同意可完成健檢且不留同意細項、不印同意書。
- 同意時各條件欄位、期間正整數、完整有效日期、未來簽署日期、本人及代理人簽名皆有前後端一致驗證。
- 變更選項、草稿恢復、再次修改與重簽、舊資料相容、原本問卷及其他六種表單回歸。
- 320／390 手機寬度、各字級及桌機後台沒有遮字、貼框或橫向溢出。
- 前後台完整流程與 A4 兩頁列印，逐頁對照來源，確認正文、紅色字、勾選及簽名位置，並檢查載入完成後直接列印。
- 共用字典產生／同步檢查、型別、必要整合測試與正式版建置。
